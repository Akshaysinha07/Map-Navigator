# Map Navigator 🗺️⚡

An interactive graph algorithms and pathfinding visualizer built with **React** and **Vite**.

## 🚀 Features

- **Interactive Graph Network**: Visualize nodes and weighted edges with a clean, dynamic canvas interface.
- **Multiple Graph Algorithms**:
  - **BFS (Breadth-First Search)**: Level-order traversal for shortest path in unweighted graphs.
  - **DFS (Depth-First Search)**: Deep exploration traversal.
  - **Dijkstra's Algorithm**: Optimal shortest path on weighted graphs with non-negative edge weights.
  - **Bellman-Ford Algorithm**: Single-source shortest path algorithm capable of handling negative edge weights.
  - **Floyd-Warshall Algorithm**: All-pairs shortest paths calculation and step-by-step matrix visualization.
- **Step-by-Step Execution**: Play, pause, step forward/backward, and adjust animation speed.
- **Data Structure Inspector**: Live state inspector showing frontier/queue, visited sets, and distance tables.
- **Code Trace Viewer**: Real-time pseudocode and execution line tracking.

## 🛠️ Tech Stack

- **React 18**
- **Vite**
- **HTML5 Canvas / SVG / CSS3**

## 💻 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm`

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Akshaysinha07/Map-Navigator.git
   cd Map-Navigator
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
